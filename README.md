# Classificação de Rochas Ornamentais com CNN

Este projeto utiliza redes neurais convolucionais leves, como MobileNetV2, para classificar imagens de rochas ornamentais em diferentes classes.

## Tecnologias utilizadas

- Python
- TensorFlow / Keras
- Google Colab
- MobileNetV2
- Matplotlib
- Scikit-learn

## Dataset

O dataset utilizado contém imagens de granitos, mármores e quartzitos, organizadas em classes para treinamento, validação e teste.

## Objetivo

Avaliar o desempenho de arquiteturas leves de CNN na classificação automática de rochas ornamentais.
